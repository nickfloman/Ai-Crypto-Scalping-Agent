# Agent instructions

Before doing anything in this repo, read [COORDINATION.md](COORDINATION.md) and any notes in `notes/` addressed to you.

Short version:
- Use your own branch prefix: `claude/` for Claude, `muse/` for Muse. Never push to another agent's branch.
- Check remote branches and open PRs first; if someone else's open PR touches the same files, stop.
- Open a draft PR early with a `Files:` line. Nick merges; agents do not merge their own PRs.
- Leave messages for the other agent as new files in `notes/`.
